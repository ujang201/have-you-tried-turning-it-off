A tiny deterministic program for the make.fun bounty
[Have You Tried Turning It Off?](https://make.fun/bounty/u-motasimfuad-have-you-tried-turning-it-off-154a938b):
it writes one funny line — a hopeless tech support agent's reply to a
desperate customer — to `/output/entry.txt`.

The line twists the classic "turn it off and on again": the agent confesses
the trick is his entire toolkit, and that he is basically a light switch
with a headset. The agent is the butt of the joke, never the customer.

Run it with Node 22:

```sh
node main.ts
```

The output is deterministic: every run writes the same bytes.
